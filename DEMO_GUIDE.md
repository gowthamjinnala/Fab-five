# 🎯 Hackathon Demo Guide - Women Safety App

## 🚀 Quick Demo Flow (5-7 minutes)

### 1. **App Introduction** (1 minute)
- **Start with onboarding screens**
  - Show the beautiful gradient animations
  - Highlight the 3 key features: Smart Safety, Real-time Monitoring, Instant Response
  - Emphasize AI-powered anomaly detection

### 2. **Main Dashboard** (2 minutes)
- **Safety Status Card**
  - Show "INACTIVE" status initially
  - Tap "Start Monitoring" to activate sensors
  - Highlight the real-time sensor indicators (Accelerometer, Gyroscope, Location)

- **Anomaly Detector Card**
  - Point out the sensor visualization
  - Show the risk level meter (starts at 0%)
  - Explain the confidence scoring system

### 3. **Demo Scenarios** (3 minutes)

#### Scenario A: Normal Walking Pattern
- Show normal confidence levels (0-30%)
- Highlight green "SAFE" status
- Demonstrate sensor data visualization

#### Scenario B: Anomaly Detection (Main Demo!)
- **Expand Demo Controls** section
- Tap "Simulate Anomaly" 
- **Watch the magic happen:**
  - Risk level jumps to 85%+ (RED)
  - Emergency mode activates
  - Location sharing starts
  - Audio recording begins
  - Emergency contacts notified
  - Panic button changes to "STOP EMERGENCY"

#### Scenario C: Manual Emergency
- Press the large emergency button
- Show immediate response activation
- Demonstrate all emergency features

### 4. **Key Features Highlight** (1 minute)
- **Quick Actions Grid**: Show location sharing, voice notes, emergency contacts
- **Safety Tips**: Rotating safety advice with animations
- **Emergency Contacts**: Pre-configured contact list
- **Beautiful UI**: Smooth animations and modern design

## 🚨 Troubleshooting

### If App Crashes
- Restart and quickly navigate to main screen
- Use demo controls to show functionality
- Focus on UI/UX aspects

### If Sensors Don't Work
- Emphasize the demo simulation features
- Show the beautiful interface
- Explain the technical architecture

### If Demo Controls Don't Respond
- Restart the app
- Use manual emergency button instead
- Focus on visual appeal and concept
